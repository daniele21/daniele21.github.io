Vision

AI that stays close to the user and the user's data.

A future where useful AI can operate directly on personal devices, under explicit user control, without making the cloud the default destination for every sensitive interaction.

Mission

Reduce the distance between a local model demo and a reliable product.

Build reusable infrastructure, validate it through real applications and publish the evidence needed to create better privacy-first products across desktop and mobile.

The foundation

Three infrastructure pillars

Each project solves a different part of the local-AI product stack. The landing keeps the first layer simple; technical detail is available when it becomes useful.

Experimental

Local LLM Server

A stable local inference layer between applications and fragmented desktop model engines.

Provides an OpenAI-compatible API, runtime lifecycle, backend abstraction, model switching and observability across GGUF and MLX workflows.

  • Desktop inference and orchestration
  • Explicit model and backend management
  • Runtime telemetry and live diagnostics

About

Infrastructure, product and communication in one direction.

I am a lead data scientist and builder working across applied AI architecture, product development and technical communication. These projects are where I test how local and open-weight models move from an experiment into something people can actually use.

The work is intentionally pragmatic:

  • local when it provides meaningful privacy, control or cost benefits;
  • cloud when the workload genuinely requires it;
  • explicit about maturity, evidence and limitations.
